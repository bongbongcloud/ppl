Running on this device only

Firebase is not configured, so entries save to this browser and will not sync to your phone. To turn on sync:

  1. Create a free project at console.firebase.google.com, add a Web app, copy the firebaseConfig.
  2. Paste those six values into const FIREBASE_CONFIG near the top of the script in index.html.
  3. Authentication → Sign-in method → enable Email/Password.
  4. Authentication → Users → Add user: email bryan@fullbody.local, password bryangym2026.
  5. Firestore Database → Create database (production mode, region asia-southeast1), then under Rules: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{doc=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == uid;
    }
  }
}
  6. Add your host (e.g. yourname.github.io) under Authentication → Settings → Authorized domains.

The password on the lock screen is the one you set in step 4 — change it there and the app follows.

Weekly totals & how to run it

  • Per muscle, per week: back 11 sets, hamstrings 10, quads 9, chest 8, delts 7.
  • Order is A → B → C, not Mon–Wed–Fri. Whenever you next get to the gym, do the next letter.
  • Anchors first, always. Short on time, cut the last superset — never an anchor.
  • Swap freely. Every exercise lists alternatives — a busy machine is not a reason to skip the slot.
  • Log RIR honestly. It is the only thing that tells a real stall apart from a bad night's sleep.
  • Deload every 6–8 weeks: same lifts and loads, two sets of everything, one week.
  • While cutting, holding anchor loads steady as bodyweight falls is the win, not a plateau.
